# 截图套壳 Screenshot Framer（源码）

自动为系统截图（PNG/JPG）和录屏（MP4）套上设备外壳的 root 模块（KernelSU / APatch / Magisk）。

## 目录

- `module/`：模块本体（脚本、`webroot/` 界面、`module.prop`、`defaults/`）。`bin/frame` 由构建生成，不在源码里。
- `src/`：核心程序 `frame` 的 C 源码（`frame.c`，依赖 `lodepng`，JPG 用 stb 单头文件，`build.sh` 会自动下载）。
- `src/bundle_ffmpeg.sh`：把 Termux 的 ffmpeg 及其依赖库打进 `module/bin/ffmpeg/`（录屏套壳用，首次构建自动执行）。
- `build_module.sh`：一键编译并打包模块 zip。

## 构建（Termux）

```
pkg install clang curl zip   # ffmpeg、binutils 会在首次构建时自动安装
sh build_module.sh
```


## 界面结构（V2.0）

- 首页：只有“截图套壳”“录屏套壳”两张卡片（壳图缩略图、开关、文件夹、输出方式）和“最近处理”，点卡片进入各自的配置页；⋮ 菜单里是运行日志和关于。
- 配置页：当前壳图（更换壳图 / 校准与预览）、文件夹、输出方式、宽高比不一致时、横屏方向，每项用底部弹层选择，选定即保存。截图和录屏各存一套：`shot_frame`、`shot_res`、`shot_mode`、`shot_rot`、`rec_frame`、`rec_res`、`rec_mode`、`rec_rot`（空 = 沿用通用值 / 自动匹配）。
- 壳图库：点壳图即选用，右上角按钮进入校准。右上角“多选”进入多选模式，勾选后点底部“删除”可批量删除（校准页里不再有删除按钮）。删除时，正在使用被删壳图的通道会改用另一个通道当前选定的壳图；另一个通道没有选定壳图（或也被删了）时，这个通道留空，即自动匹配。
- 校准页：预览固定在上方，下面按“位置 / 四角 / 方向 / 匹配”标签切换；“内容缩放”存为壳图配置里的 `scale`。
- 透视壳图的手机顶部：`frame detect` 输出 `top=`（0 上 / 1 右 / 2 下 / 3 左，-1 未知），依据屏幕区域里的前置摄像头 / 刘海开孔判断。

## 录屏套壳

概览页有两个独立开关：“截图套壳”和“录屏套壳”（默认关闭），互不影响。录屏结束后用 ffmpeg 重新编码：画面放进壳图的屏幕区域，并用壳图屏幕区域的真实形状做蒙版（`frame vprep` 生成），圆角处不会溢出；音轨直接复制。

- 匹配：截图按分辨率完全一致匹配；录屏按宽高比匹配（2% 容差，横竖屏均可），因此任意录屏分辨率都能用。
- 文件夹：`module/recdirs.sh` 负责找录屏文件夹，设置页里手动指定优先；留空时监听所有检测到的文件夹（常见路径 + 名字含 screen record、录屏、屏幕录制的文件夹）。还没有录屏文件夹时，`rescan.sh` 会等系统创建后自动开始监听。

## 透视（3D）壳图

壳图的屏幕区域是倾斜的四边形（手持、斜放的样机图）时，自动检测屏幕四个角（v1.5.1 起：对轮廓的每个方向求“支撑线”，统计贴着支撑线的轮廓点数，四条真正的直边会形成四个尖锐的峰，圆角再大也不会形成峰；再对每个峰做最小二乘直线拟合并求交点。旧算法只取轮廓的极值点，圆角很大时会把一个角算到很远的地方，已改为仅作备用），截图用透视变换贴进去，录屏用 ffmpeg 的 `perspective` 滤镜。蒙版仍取壳图透明区域的真实形状，所以圆角、打孔、手指遮挡都照样处理。

- 输出尺寸固定为壳图尺寸。
- 屏幕内容方向：自动（竖屏内容放进横着的屏幕时，按设置里的壳图方向旋转），或手动 0/90/180/270（顺时针）。
- 四角可在“壳图”页手动微调，保存在壳图配置的 `quad=x0,y0,x1,y1,x2,y2,x3,y3`（左上、右上、右下、左下，壳图像素）和 `orient=` 里。
- 校准贴合反馈（v1.5.1）：“四角”标签里，四边形轮廓和圆点按与自动检测四角的偏差变色（绿 ≤ 容差，橙 ≤ 4 倍容差，红更大；容差为壳图长边的 0.2%，至少 3 像素）；四个角都在容差内时屏幕区域变绿、提示“四角已贴合屏幕”，并轻振一下。
- 命令行：`frame detect` 会输出 `persp=` 和 `quad=`；`compose`/`vprep` 支持 `--quad`、`--orient`。

## 第三方组件

- LodePNG（zlib 许可）
- stb_image、stb_image_write（公有领域）
- FFmpeg（LGPL/GPL，取自 Termux 软件包，仅随模块打包使用）

## v2.0 更新

- 屏幕分辨率改为全局设置：首页新增“屏幕分辨率”入口，二级页面里选“自动匹配”（本机分辨率）或“手动输入”并保存，配置项 `screen_res=WxH`（空 = 自动）。截图和录屏、所有壳图共用，不再放在每套壳图的校准页里；壳图配置里原来的 `ref_w/ref_h` 不再生效。
- 校准页“位置”标签也有贴合反馈：水平、垂直偏移让内容边缘与检测到的屏幕边缘一致、且内容缩放为 100% 时，预览下方提示“四边已贴合屏幕”。
- 3D 透视壳图下被固定的选项（输出方式、宽高比不一致时）在截图/录屏配置页显示“……（3D透视壳图固定）”，点开只给说明、不能改；在校准页手动指定方向后，“横屏时壳图方向”同样固定。
- 选择壳图页右上角“多选”改为“删除”。
- 关于页加入 GitHub 链接，并更新了使用说明和功能介绍。
- 自动检测屏幕四角改用“支撑线峰值”方法，校准页四角贴合反馈，删除壳图移到选择页并支持多选、删除后截图/录屏互相回退。
