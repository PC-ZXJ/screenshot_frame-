# 截图套壳 Screenshot Framer

自动为系统截图（PNG / JPG）和录屏（MP4）套上设备外壳的 root 模块，支持 KernelSU、APatch、Magisk（仅 arm64）。截图或录屏完成后自动处理，并以原文件名在原位置保存。模块自带 WebUI，在管理器里直接打开即可设置。

## 功能特点

- **截图和录屏两个独立通道**：各有开关，各自选择壳图、监听文件夹和输出方式，可以用不同的壳图。
- **平面壳图和 3D 透视壳图**：屏幕区域是倾斜四边形的样机图（手持、斜放）也能用，截图做透视变换，录屏用 FFmpeg 的 `perspective` 滤镜。
- **自动识别屏幕区域**：以壳图透明区域的真实形状做蒙版，圆角、打孔、手指遮挡都照样处理，画面不会溢出到圆角外。
- **3D 壳图自动检测**：屏幕四角（圆角再大也不会偏）和手机顶部（依据前置摄像头开孔）。
- **校准页实时预览和贴合反馈**：
  - 位置：水平、垂直偏移和内容缩放。
  - 四角和方向：3D 壳图才有，四角可拖动圆点或用滑块微调。
  - 调“四角”时，轮廓和圆点按与自动检测结果的偏差变色（绿色贴合、橙色略偏、红色偏得多）；四个角都贴合，或位置偏移让内容边缘贴合屏幕时，预览区闪一下绿色、轻振一下，并提示“四角（四边）已贴合屏幕”。
- **屏幕分辨率全局设置**：默认自动匹配本机分辨率，也可手动输入。
- **壳图管理**：在界面内导入壳图；选择壳图页可以多选批量删除，删除后正在使用它的通道会自动回退。
- **状态显示**：首页顶部显示监听服务和 FFmpeg 的状态。
- 其他：PNG 截图可无损输出（像素 1:1 保留）；录屏保留声音；支持横屏截图和横屏录屏；区域截图、长截图等尺寸不符的自动跳过。

## 使用

1. 刷入模块（装完重启），在管理器里打开模块界面。
2. 模块不自带壳图，请自备你机型的壳图：PNG 格式，屏幕区域透明，且被边框完全包围。在“更换壳图”里添加。
3. 首页打开“截图套壳”和（或）“录屏套壳”的开关。
4. 点“校准与预览”检查壳图是否对准屏幕，调整后点右上角“保存”。

截图套壳默认监听 `/sdcard/Pictures/Screenshots`，录屏套壳默认自动检测录屏文件夹，都可以在配置页修改。

### 3D 透视壳图的固定选项

使用 3D 透视壳图时，下列选项由壳图本身和校准页决定，配置页里标注“3D透视壳图固定”且不能更改：

| 选项 | 3D 壳图下的行为 |
|---|---|
| 输出方式 | 输出为壳图尺寸 |
| 宽高比不一致时 | 拉伸贴合屏幕四角 |
| 横屏时壳图方向 | 内容方向由校准页的“方向”决定：选“自动”时按检测到的手机顶部摆正，横屏内容再逆时针转 90°，无法判断顶部时同样按逆时针 90° 处理；也可手动选 0° / 90° / 180° / 270°（顺时针） |

### 匹配规则

- 截图：尺寸必须与“屏幕分辨率”完全一致（横竖屏均可）才会套壳。
- 录屏：按宽高比匹配（2% 容差，横竖屏均可），所以任意录屏分辨率都能用。

## 目录结构

- `module/`：模块本体（脚本、`webroot/` 界面、`module.prop`、`defaults/`）。`module/bin/` 里的内容由构建生成，不在源码里。
- `src/`：核心程序 `frame` 的 C 源码（`frame.c`，依赖 `lodepng`；JPG 编解码用 stb 单头文件，构建时自动下载）。
- `src/bundle_ffmpeg.sh`：把 Termux 的 ffmpeg、ffprobe 及其依赖库打进 `module/bin/ffmpeg/`（录屏套壳用）。
- `build_module.sh`：一键编译并打包模块 zip。

## 构建（Termux）

先装构建工具：

```
pkg install clang curl zip
```

然后在源码目录里构建：

```
sh build_module.sh
```

首次构建需要联网，会自动完成这些事：下载 stb 头文件、安装 ffmpeg 和 binutils（`pkg install`）、把 ffmpeg 打包进 `module/bin/ffmpeg/`。生成的 `screenshot_frame_<版本>.zip` 是自包含的，可直接在管理器里刷入，装完不依赖 Termux。版本号在 `module/module.prop` 里修改。


## 配置文件

数据目录是 `/data/adb/screenshot_frame`：`config`（全局设置）、`profiles/<名称>.conf`（每套壳图的校准）、`frames/`（壳图文件）、`bin/`（核心程序和 FFmpeg 的工作副本）、`log.txt`（运行日志）。升级模块会保留这些数据，卸载模块不会自动清理。

`config`（`key=value`）：

| 键 | 说明 |
|---|---|
| `enabled` / `rec_enabled` | 截图 / 录屏套壳开关（1 开，0 关） |
| `watch_dir` / `rec_dir` | 截图 / 录屏文件夹；`rec_dir` 留空 = 自动检测 |
| `screen_res` | 全屏截图须有的分辨率 `WxH`；留空 = 本机分辨率 |
| `shot_frame` / `rec_frame` | 截图 / 录屏使用的壳图；留空 = 自动匹配 |
| `shot_res` / `rec_res` | 输出方式：`native`（保持原始分辨率）或 `frame`（壳图尺寸） |
| `shot_mode` / `rec_mode` | 宽高比不一致时：`cover`（等比填充）或 `stretch`（拉伸填充） |
| `shot_rot` / `rec_rot` | 平面壳图、横屏内容时壳图的旋转方向：`ccw` 或 `cw` |
| `active`、`res`、`mode`、`rot` | 上面各项留空时使用的通用值 |

`profiles/<名称>.conf`：

| 键 | 说明 |
|---|---|
| `frame` | 壳图文件名 |
| `dx`、`dy` | 内容的水平、垂直偏移（壳图像素） |
| `scale` | 内容缩放（0.5–1.5，默认 1），调小会在屏幕四周留出黑边 |
| `quad` | 3D 壳图的屏幕四角 `x0,y0,x1,y1,x2,y2,x3,y3`（左上、右上、右下、左下，壳图像素）；没有则用自动检测的结果 |
| `orient` | 3D 壳图的内容方向 `0` / `90` / `180` / `270`（顺时针）；没有则自动 |

## 工作原理

- **监听**：`inotifyd` 监听截图和录屏文件夹，新文件稳定后调用处理脚本（`process.sh` 处理截图，`process_video.sh` 处理录屏），`rescan.sh` 会在录屏文件夹还没创建时等待它出现。
- **屏幕区域检测**：取壳图中央那块连通的透明区域作为屏幕。平面壳图用它的外接矩形；倾斜的 3D 壳图则求出四条真正的直边再取交点。具体做法是对轮廓的每个方向求“支撑线”，统计贴着支撑线的轮廓点数，四条直边会形成四个尖锐的峰，圆角再大也不形成峰，再对每个峰做最小二乘直线拟合。
- **手机顶部检测**：在屏幕区域里找前置摄像头或刘海的开孔，判断它靠近哪条边。`frame detect` 输出 `top=`（0 上 / 1 右 / 2 下 / 3 左，-1 表示没找到）。
- **截图**：`frame compose` 把截图放进屏幕区域（3D 壳图做透视变换），再叠上壳图。
- **录屏**：`frame vprep` 生成缩放、裁剪、透视参数和蒙版，FFmpeg 重新编码画面并直接复制音轨。

### 核心程序命令行

```
frame detect <frame.png>
frame compose <frame.png> <in.png|jpg> <out.png|jpg> [--dx N --dy N --scale F --mode cover|stretch --rot cw|ccw --res native|frame --quality N --bg RRGGBB]
frame vprep ...                  # 录屏用，参数见 frame.c 文件头注释
```

3D 壳图可另加 `--quad x0,y0,x1,y1,x2,y2,x3,y3` 和 `--orient auto|0|90|180|270`。

## 第三方组件

- LodePNG（zlib 许可）：PNG 编解码
- stb_image、stb_image_write（公有领域）：JPG 编解码
- FFmpeg（LGPL / GPL，取自 Termux 软件包，仅随构建出的模块打包，不在本仓库中）
