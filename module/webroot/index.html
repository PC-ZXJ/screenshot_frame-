关于与使用须知

  

    
截图套壳

    
Screenshot Framer

    
自动监听系统截图和录屏，为全屏截图和全屏录屏套上设备外壳（支持平面壳图和 3D 透视壳图），并以原文件名在原位置保存。截图支持 PNG 和 JPG，录屏支持 MP4。


    

      
怎么用

      
    
        
  • 首页有“截图套壳”和“录屏套壳”两个入口，各自有开关；点进去可以单独选壳图、文件夹和输出方式，两边互不影响，可以用不同的壳图。
    • 
        
  • 点“更换壳图”选择壳图，也可以在那里添加新的壳图；在“选择壳图”页点右上角“删除”，可以多选后批量删除。
    • 
        
  • “校准与预览”里可以微调壳图并实时看到效果：位置（水平、垂直偏移和内容缩放），以及 3D 透视壳图才有的四角和方向。校准完点右上角“保存”。
    • 
        
  • 首页的“屏幕分辨率”是全局设置，默认自动匹配本机分辨率，一般不用改；想手动指定时，可以在里面输入并保存。
    • 
        
  • 开关点一下立即生效；文件夹、输出方式等选项选定后立即保存。
    • 
      

    


    

      
主要功能

      
    
        
  • 首页顶部显示监听服务和 FFmpeg 的状态，点 FFmpeg 状态可以看原因；FFmpeg 异常时录屏不会被处理，截图不受影响。
    • 
        
  • 自动监听截图文件夹和录屏文件夹，截图后数秒内完成套壳并原位替换；录屏结束后自动处理。文件夹可自动检测或手动指定。
    • 
        
  • PNG 截图无损输出：截图像素 1:1 保留，不重新压缩；也可改为按壳图尺寸输出。JPG 截图套壳后以最高画质重新保存，壳图外的透明区域填白。
    • 
        
  • 自动识别壳图的屏幕区域（含圆角与挖孔），画面不会溢出到圆角外。
    • 
        
  • 支持 3D 透视壳图：自动检测屏幕四角（圆角再大也不会偏）和手机顶部（依据前置摄像头开孔），截图和录屏按透视变形贴进屏幕，手指遮挡处照样处理。
    • 
        
  • 校准实时反馈：调整“四角”时，轮廓和圆点按偏差变色（绿色贴合、橙色略偏、红色偏得多）；四个角都贴合，或“位置”的水平、垂直偏移让内容边缘贴合屏幕时，预览区会闪一下绿色并轻振，同时提示“四角（四边）已贴合屏幕”。
    • 
        
  • 3D 透视壳图的输出方式、宽高比处理和横屏时壳图方向都是固定的：输出为壳图尺寸、拉伸贴合屏幕四角、内容方向由校准页的“方向”决定。这几个选项会标注“3D透视壳图固定”，且不能更改。
    • 
        
  • 壳图的屏幕圆角比你的手机大时，状态栏的时间和电量会贴着边；可以在“位置”里把“内容缩放”调小一点，留出黑边。
    • 
        
  • 删除壳图时，正在使用它的截图或录屏会改用另一边当前选定的壳图；另一边没有选定壳图时留空，即自动匹配。
    • 
        
  • 仅处理全屏截图和全屏录屏；区域截图、长截图等尺寸不符的会自动跳过。截图按“屏幕分辨率”匹配，录屏按宽高比匹配，任意录屏分辨率都可用。
    • 
        
  • 支持横屏截图和横屏录屏；声音保留。
    • 
        
  • 壳图在界面内导入，模块自动保存，无需手动创建文件夹。
    • 
      

    


    

      
使用须知

      
    
        
  • 套壳会直接替换原截图和录屏，原文件无法恢复。
    • 
        
  • 录屏套壳需要重新编码视频，耗时与录屏时长、分辨率相关；处理期间请勿删除或移动该录屏。处理进度和结果可在首页“最近处理”和“运行日志”中查看。仅处理 MP4。
    • 
        
  • 需要 root 权限，设备架构为 arm64。
    • 
        
  • 支持的管理器：KernelSU 及其衍生版（如 KernelSU Next、SukiSU Ultra）、APatch，可直接在管理器中打开本界面；Magisk 自身没有模块界面，需借助 MMRL 等支持 WebUI 的工具打开。目前仅在 KernelSU 上测试，其他管理器未逐一验证。
    • 
        
  • 模块不自带壳图，请自备你机型的壳图：PNG 格式，屏幕区域透明，且被边框完全包围。
    • 
        
  • 升级模块会保留设置和壳图。卸载模块不会自动清理数据目录，如需彻底清除，请手动删除 /data/adb/screenshot_frame。
    • 
        
  • 套壳没有反应时，先查看“运行日志”；监听服务异常时，请重启手机。
